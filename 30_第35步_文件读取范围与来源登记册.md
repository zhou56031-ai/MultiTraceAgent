## 1. 为什么先做这一件事

想象小明上传一本 80 页的 PDF，模型实际上只看到前 20 页，又因文字太长只收到前 12000 字符。如果页面只显示“分析完成”，小明很容易以为整本都读完了。现在要把“看了哪一部分”随工具结果一起交出来。

本步不会增加向量数据库，也不会把上传文件自动送进 RAGFlow。读取文件和 Embedding 是不同工作；这条改造只描述实际读取边界，不需要调用百炼。

本步期望：读长文本时返回文件编号 `[F1]`、文件名、读取范围、是否截断，再返回真正给模型的正文。网页来源编号在第 36 步增加，任务保存与页面展示在 38、39 步接上。

## 3. 建立任务自己的资料登记册

把登记册想象为小明这次委托的一本便签本。搜索助手和文件工具都拿到同一本；小红的另一次委托拿到另外一本。这里先定义“怎样创建和取用便签本”，第 38 步才在每次 HTTP 任务开始时发放它。

### 新建 `learning/api/evidence.py`

这是本步完整文件，写入以下内容：

```python
"""一次任务共用的来源登记册；子助手与同步工具通过 ContextVar 取得它。"""

from contextvars import ContextVar
from copy import deepcopy
from threading import Lock
from urllib.parse import quote, urlsplit

_evidence: ContextVar["EvidenceRegistry | None"] = ContextVar("evidence", default=None)
_task_id: ContextVar[str | None] = ContextVar("task_id", default=None)


class EvidenceRegistry:
    def __init__(self) -> None:
        self._sources: list[dict] = []
        self._keys: dict[tuple, str] = {}
        self._lock = Lock()

    def add(self, kind: str, key: tuple, data: dict) -> dict:
        # 多个并行子助手可能在不同工具线程中登记；编号必须在锁内生成。
        with self._lock:
            identity = (kind, *key)
            if identity in self._keys:
                return deepcopy(next(s for s in self._sources if s["id"] == self._keys[identity]))
            prefix = "S" if kind == "web" else "F"
            number = 1 + sum(source["kind"] == kind for source in self._sources)
            source = {**deepcopy(data), "id": f"{prefix}{number}", "kind": kind}
            self._keys[identity] = source["id"]
            self._sources.append(source)
            return deepcopy(source)

    def snapshot(self) -> list[dict]:
        with self._lock:
            return deepcopy(self._sources)


def get_evidence() -> EvidenceRegistry | None:
    return _evidence.get()


def set_evidence(registry: EvidenceRegistry):
    return _evidence.set(registry)


def reset_evidence(token) -> None:
    _evidence.reset(token)


def set_task_id(task_id: str):
    return _task_id.set(task_id)


def reset_task_id(token) -> None:
    _task_id.reset(token)


def get_task_id() -> str | None:
    return _task_id.get()


def safe_web_url(value: str) -> str | None:
    try:
        parsed = urlsplit(value)
        if parsed.scheme not in {"https", "http"} or not parsed.hostname or parsed.username or parsed.password:
            return None
        if any(ord(char) < 32 for char in value):
            return None
        return quote(value, safe=":/?#[]@!$&'*+,;=%~.-_")
    except ValueError:
        return None


def append_source_references(content: str, sources: list[dict] | None = None) -> str:
    """只附上实际工具登记的目录，不声称来源能自动证明模型的每条结论。"""
    if sources is None:
        registry = get_evidence()
        sources = registry.snapshot() if registry else []
    if not sources:
        return content
    lines = ["## 本次工具来源", "", "以下是本次工具实际取得的资料；引用仍需对照原文核查。", ""]
    for source in sources:
        label = source["id"]
        title = str(source.get("title") or source.get("filename") or "资料").replace("\n", " ")
        title = title.replace("\\", "\\\\").replace("[", "\\[").replace("]", "\\]")
        url = safe_web_url(str(source.get("url", "")))
        if source["kind"] == "web" and url:
            lines.append(f"- [{label}] [{title}]({url})")
        else:
            lines.append(f"- [{label}] {title}：{source.get('scope', '读取范围未记录')}")
    # 按本次登记册重建附录，避免模型或前一次调用留下过期的来源目录。
    body = content.split("\n\n## 本次工具来源\n", 1)[0]
    return body.rstrip() + "\n\n" + "\n".join(lines) + "\n"
```

### 3.1 类、对象与三个成员变量，代入一个具体过程

`EvidenceRegistry` 是“便签本的制作规则”。执行 `a = EvidenceRegistry()` 才产生一个具体对象。再执行 `b = EvidenceRegistry()` 得到另一本，A 的来源不会自动出现在 B。

`__init__` 在创建对象时被调用；这次 `self` 指向刚创建的 a。`self._sources = []` 给 a 建立来源列表，`self._keys = {}` 建立去重索引，`self._lock = Lock()` 给 a 建立登记时共用的锁。它们不是所有任务共用的一组类变量。

| 变量 | 小明首次读文件前 | 读完后的用途 |
| --- | --- | --- |
| `_sources` | `[]` | 保存实际登记的条目，如 id=F1、filename=长文.txt、scope=返回前12000字符 |
| `_keys` | `{}` | 将“文件名+修改时间+范围”映射到 F1，再次读取相同版本不重复编号 |
| `_lock` | 一个 Lock 对象 | 并行子助手可能在不同线程登记，先获得锁的工具登记完，其他工具再继续 |
| `identity` | 由 `kind` 和 `key` 拼出的 tuple | 判断是否登记过；不是模型传来的来源编号 |
| `prefix` / `number` | file 对应 F，首次为 1 | 组装出 F1；网页单独使用 S1、S2 |
| `source` | 当前完整条目字典 | 放进列表，并复制一份交回调用者 |

`add(kind, key, data)` 由工具调用。kind 表示网页还是文件，key 表示用于去重的身份，data 才是要公开的元数据。`with self._lock` 包住查重与编号，防止两个线程同时看见“还没有 F1”，都生成同一个编号。

`snapshot()` 返回复制后的列表；调用者改它不会反过来改登记册。这里的 deepcopy 是复制数据，不是复制文件内容或创建第二个任务。

### 3.2 ContextVar 这次具体传什么

`_evidence` 保存当前执行路线指向的登记册对象。`set_evidence(registry)` 返回旧状态 Token；`get_evidence()` 让深层工具找到本次登记册；`reset_evidence(token)` 在结束时恢复原状态。它不替我们把数据存入 SQLite。

例如 API 发给小明一本登记册 a → 主任务调用子助手 → 子助手用 `asyncio.to_thread` 执行同步工具 → 线程继承上下文，取得的仍是 a。锁保护的正是不同线程操作同一本 a 的情况。新任务重新创建 b，不复用 a。

`_task_id` 与 `set_task_id/get_task_id/reset_task_id` 则管理这次任务的编号，供第 38 步通知与账本接入使用。它与前面的 thread_id 不同：thread_id 是整段对话的号码，task_id 是其中一次提问的号码。

### 3.3 其余两个普通函数先认识职责

`safe_web_url(value)` 由搜索工具与来源附录调用，只接受没有用户名密码的 http/https URL，并编码容易破坏链接的字符；失败返回 None。它只检查地址形状，不证明网页事实可信，也不访问网页。

`append_source_references(content, sources=None)` 由报告与主任务调用。省略 sources 时读取当前登记册，空登记册则原样返回正文；否则为实际条目建立“本次工具来源”目录。它会用当前目录替换同名旧附录，防止反复追加。第 36 步会用真实的工具入口接通它。

from pathlib import Path

import pandas as pd
from docx import Document
from langchain_core.tools import tool
from pypdf import PdfReader

from api.monitor import monitor
from utils.path_utils import resolve_session_file


def extract_file_text(path: Path) -> str:
    """把一个已定位的会话文件转换成给模型看的文字。"""
    suffix = path.suffix.lower()
    if suffix in {".txt", ".md"}:
        return path.read_text(encoding="utf-8")
    if suffix == ".docx":
        document = Document(path)
        return "\n".join(paragraph.text for paragraph in document.paragraphs)
    if suffix == ".pdf":
        reader = PdfReader(path)
        return "\n".join(page.extract_text() or "" for page in reader.pages[:20])
    if suffix == ".xlsx":
        frame = pd.read_excel(path, sheet_name=0, nrows=100)
        return (
            f"列名：{', '.join(map(str, frame.columns))}\n"
            f"读取行数：{len(frame)}\n"
            f"{frame.head(10).to_string(index=False)}"
        )
    raise ValueError(f"不支持的文件类型：{suffix or '无扩展名'}")


@tool
def read_file_content(filename: str) -> str:
    """读取当前会话中的 txt、md、docx、pdf 或 xlsx 文件。"""
    try:
        target = resolve_session_file(filename)
        if not target.is_file():
            return f"错误：文件不存在：{target.name}"
        monitor.report_tool("read_file_content", {"filename": target.name})
        text = extract_file_text(target)
        return text[:12000] or "文件中没有可提取的文字"
    except (ValueError, RuntimeError, OSError, UnicodeError) as exc:
        return f"读取失败：{exc}"
    except Exception as exc:
        return f"读取失败：{type(exc).__name__}"
```

from pathlib import Path

import pandas as pd
from docx import Document
from langchain_core.tools import tool
from pypdf import PdfReader

from api.monitor import monitor
from api.evidence import EvidenceRegistry, get_evidence
from utils.path_utils import resolve_session_file


MAX_TEXT_CHARS = 12000


def extract_file_details(path: Path) -> tuple[str, dict]:
    """返回有界正文和读取说明；不把未读取部分说成已经分析。"""
    suffix = path.suffix.lower()
    metadata = {"format": suffix.lstrip("."), "truncated": False}
    if suffix in {".txt", ".md"}:
        text = path.read_text(encoding="utf-8")
        scope = "UTF-8 文本"
    elif suffix == ".docx":
        document = Document(path)
        text = "\n".join(paragraph.text for paragraph in document.paragraphs)
        metadata.update(paragraphs=len(document.paragraphs), tables_omitted=len(document.tables))
        scope = f"Word 正文 {len(document.paragraphs)} 段；不读取表格、图片、页眉页脚"
        metadata["truncated"] = bool(document.tables)
    elif suffix == ".pdf":
        reader = PdfReader(path)
        total = len(reader.pages)
        selected = min(total, 20)
        texts = [page.extract_text() or "" for page in reader.pages[:20]]
        text = "\n".join(texts)
        metadata.update(total_pages=total, pages_read=selected, empty_pages=sum(not t.strip() for t in texts))
        metadata["truncated"] = selected < total
        scope = f"PDF 共 {total} 页，仅提取第 1～{selected} 页文字；不做 OCR，图片及扫描页可能无文字"
    elif suffix == ".xlsx":
        with pd.ExcelFile(path, engine="openpyxl") as book:
            sheet = book.sheet_names[0]
            sheet_count = len(book.sheet_names)
            # 第101行仅判断是否还有后续数据，不交给模型；总行数不作猜测。
            sample = pd.read_excel(book, sheet_name=0, nrows=101)
        frame = sample.head(100)
        shown = min(10, len(frame))
        cell_truncated = any(len(str(value)) > 200 for value in frame.head(10).to_numpy().flat)
        text = (
            f"列名：{', '.join(map(str, frame.columns))}\n"
            f"读取行数：{len(frame)}\n"
            f"{frame.head(10).to_string(index=False, max_cols=None, max_colwidth=200)}"
        )
        metadata.update(sheet=sheet, sheet_count=sheet_count, rows_read=len(frame), rows_shown=shown,
                        more_rows=len(sample) > 100, cell_char_limit=200, cell_truncated=cell_truncated)
        metadata["truncated"] = len(frame) > shown or len(sample) > 100 or sheet_count > 1 or cell_truncated
        scope = (f"Excel 共 {sheet_count} 个工作表，仅首表「{sheet}」；最多取 100 行数据，"
                 f"本次取 {len(frame)} 行、正文展示前 {shown} 行；总行数未统计；单元格展示最多 200 字符")
    else:
        raise ValueError(f"不支持的文件类型：{suffix or '无扩展名'}")

    body = text[:MAX_TEXT_CHARS]
    char_truncated = len(text) > len(body)
    metadata.update(extracted_chars=len(text), returned_chars=len(body), char_truncated=char_truncated)
    metadata["truncated"] = metadata["truncated"] or char_truncated
    scope += f"；所选范围提取 {len(text)} 字符，返回前 {len(body)} 字符"
    if char_truncated:
        scope += "（正文已截断，后续内容未返回）"
    metadata["scope"] = scope
    return body, metadata


def extract_file_text(path: Path) -> str:
    """兼容前面教程的普通函数入口；返回有界的提取文字。"""
    text, _ = extract_file_details(path)
    return text


@tool
def read_file_content(filename: str) -> str:
    """读取当前会话中的 txt、md、docx、pdf 或 xlsx 文件。"""
    try:
        target = resolve_session_file(filename)
        if not target.is_file():
            return f"错误：文件不存在：{target.name}"
        monitor.report_tool("read_file_content", {"filename": target.name})
        text, metadata = extract_file_details(target)
        registry = get_evidence() or EvidenceRegistry()
        source = registry.add("file", (filename, target.stat().st_mtime_ns, metadata["scope"]),
                              {"filename": filename, **metadata})
        monitor.report_sources(registry.snapshot())
        return (f"[{source['id']}] 文件：{filename}\n【读取范围】{metadata['scope']}\n"
                "回答时引用此文件编号；仅据已返回内容作答，不声称已通读未读取部分。\n\n"
                + (text if text.strip() else "文件中没有可提取的文字；扫描 PDF 需要另行 OCR"))
    except (ValueError, RuntimeError, OSError, UnicodeError) as exc:
        return f"读取失败：{exc}"
    except Exception as exc:
        return f"读取失败：{type(exc).__name__}"
```

### 5.1 extract_file_details 为什么存在

以前 `extract_file_text(path)` 只交回字符串，调用者不知道它被截取过多少。现在新函数交回 `(body, metadata)`：body 是模型真正可见的正文，metadata 是解释范围的字典。保留 `extract_file_text` 作为兼容入口，让旧调用仍能取得文字。

`path` 来自已经过 `resolve_session_file` 检查的 Path，不是随便接收服务器上的任意绝对路径。

| 分支 | 实际读取 | 必须告诉用户的边界 |
| --- | --- | --- |
| TXT/MD | UTF-8 文本 | 正文最多返回12000字符；更多内容不交给模型 |
| DOCX | 正文段落 | 不读表格、图片、页眉页脚；段落拼接后同样截断 |
| PDF | 前20页的文字层 | 记录总页数与实际页数；不做OCR，扫描页可能无文字 |
| XLSX | 首表，最多100行数据 | 为判断后续数据额外探测第101行；正文只展示前10行，其他表不读，总行数不猜测；单元格展示最多200字符 |

Excel 里 `sample` 是最多101行的探测结果，`frame` 是其中前100行，`shown` 是真正预览的行数，`cell_truncated` 表示展示中的长单元格会省略。不要把 `len(frame)=100` 说成整个工作表只有100行。

PDF 的 `texts` 是选中页面的文字列表，`empty_pages` 是其中没有提取文字的页数；空白不等于该页在视觉上没有信息。这里不会尝试识别图片。

### 5.2 三个字符数字代入长文本

假设所选范围拼接后共有13008字符：`len(text)=13008`，`MAX_TEXT_CHARS=12000`，`body=text[:12000]`。metadata 记录 extracted_chars=13008、returned_chars=12000、char_truncated=True。

extracted_chars 只对应这次所选范围，不代表80页整份PDF的字符总数。`truncated` 是总体限制标记，`scope` 才给出具体限制；即使某种格式未触发字符截断，仍要读 scope 判断是否排除了表格或图片。

### 5.3 read_file_content 的完整路线

```text
模型传 filename=长文.txt
→ resolve_session_file 确定当前会话内路径
→ 确认文件存在
→ report_tool 说明开始读取
→ extract_file_details 得到正文与范围
→ 取本任务登记册；独立直调没有上下文时临时创建一本
→ add 登记文件名、版本与范围，取得 F1
→ report_sources 报告元数据
→ 把 F1、读取范围、正文交回模型
```

`target.stat().st_mtime_ns` 用于区分同名文件的修改版本，不是防伪指纹。单独直接调用工具时的临时登记册只用于本次结果；跨工具共用由第 38 步负责。

两个 except 保持“工具错误作为文字返回”的既有接口：已知路径、编码、I/O错误给出说明，其余异常只报告类型。失败时不登记一个不存在的成功来源。

import sys
from pathlib import Path
from tempfile import TemporaryDirectory

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

import pandas as pd
from docx import Document
from pypdf import PdfWriter
from api.context import set_session_context, set_thread_context, reset_session_context
from api.evidence import EvidenceRegistry, set_evidence, reset_evidence
from tools.upload_file_read_tool import extract_file_details, read_file_content


def main():
    with TemporaryDirectory() as folder:
        root = Path(folder)
        (root / "长文.txt").write_text("开头" + "甲" * 13000 + "末尾未返回", encoding="utf-8")
        text, meta = extract_file_details(root / "长文.txt")
        assert len(text) == 12000 and meta["char_truncated"]
        assert "末尾未返回" not in text and "已截断" in meta["scope"]
        document = Document()
        document.add_paragraph("正文段落")
        document.add_table(rows=1, cols=1).cell(0, 0).text = "表格不读取"
        document.save(root / "说明.docx")
        text, meta = extract_file_details(root / "说明.docx")
        assert text == "正文段落" and meta["tables_omitted"] == 1
        writer = PdfWriter()
        for _ in range(22):
            writer.add_blank_page(width=200, height=200)
        writer.write(root / "页数.pdf")
        _, meta = extract_file_details(root / "页数.pdf")
        assert meta["pages_read"] == 20 and meta["total_pages"] == 22 and meta["empty_pages"] == 20
        with pd.ExcelWriter(root / "订单.xlsx", engine="openpyxl") as book:
            pd.DataFrame({"订单": range(105)}).to_excel(book, sheet_name="订单", index=False)
            pd.DataFrame({"保留": [1]}).to_excel(book, sheet_name="未读表", index=False)
        _, meta = extract_file_details(root / "订单.xlsx")
        assert meta["rows_read"] == 100 and meta["rows_shown"] == 10 and meta["more_rows"]
        assert meta["sheet_count"] == 2 and "总行数未统计" in meta["scope"]
        registry = EvidenceRegistry()
        token = set_evidence(registry)
        path_token = set_session_context(folder)
        thread_token = set_thread_context("scope-example")
        try:
            response = read_file_content.invoke({"filename": "长文.txt"})

            assert len(registry.snapshot()) == 1

        finally:
            reset_session_context(path_token, thread_token)
            reset_evidence(token)
    print("通过：TXT字符截断、Word排除表格、PDF前20页与无OCR、Excel首表100行/展示10行、来源编号与越界拒绝")
